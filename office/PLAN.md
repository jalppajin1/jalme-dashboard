## 1. 레퍼런스 분석

| | agent-arcade | 우리가 만들 것 |
|---|---|---|
| 형태 | VS Code / Cursor 확장 | 웹페이지 (폰·PC 브라우저) |
| 하는 일 | Claude Code 터미널 세션을 픽셀 캐릭터로 **보여주기만** 함 | AI 팀장들이 **실제로 회의하고 실행안을 냄** |
| 모델 | Claude Code만 | Claude · GPT · Gemini · Grok · Kimi · DeepSeek 등 아무거나, 팀장마다 바꿔 끼움 |
| 가져올 것 | 픽셀 오피스 비주얼, 캐릭터 상태(타이핑/말하기/걷기), 클릭해서 상세 보기 | |

agent-arcade 자체에는 "여러 모델끼리 회의" 기능이 없습니다. 친구분 영상처럼 동작하게 하려면
**여러 모델을 한 키로 부를 수 있는 OpenRouter** 를 쓰고, 회의 진행은 우리가 직접 짜야 합니다.

## 2. 컨셉

> "대표는 안건만 던진다. 팀장들이 회의실에 모여 각자 관점에서 토론하고, 비서실장이 담당·기한이 붙은 실행안으로 정리해 보고한다."

### 조직도 (기본값 — 설정에서 이름·역할·모델 모두 변경 가능)

| 자리 | 역할 | 기본 모델 | 이유 |
|---|---|---|---|
| 비서실장 | 회의 진행, 최종 보고서 | Claude | 정리·구조화 강함 |
| 운영본부장 | 8개 매장 운영·원가·인력 | GPT | 실무 계획·숫자 |
| 마케팅팀장 | 브랜드·SNS·배달앱 | Gemini | 멀티모달·콘텐츠 아이디어 |
| 트렌드리서처 | 시장·경쟁·SNS 반응 | Grok | X(트위터) 기반 최신 반응 |
| 개발사업팀장 | 부동산 매입→디벨롭→매각 | Kimi | 긴 문서(등기·계약서) 처리 |
| 숙박TF장 | 숙박업 진출 준비 | DeepSeek | 저렴하게 브레인스토밍 |

### 회의 흐름
1. 대표가 안건 입력 + 참석자 선택
2. 캐릭터들이 책상에서 회의 테이블로 걸어옴
3. 비서실장이 개회: 안건 정리 + 팀장별 검토 포인트 지정
4. 팀장들이 순서대로 발언 (앞사람 발언을 다 보고 말함, 겹치면 동의/반론만)
5. (선택) 2바퀴째: 반론·보완
6. 비서실장이 **결론 / 실행항목(담당·기한) / 대표 결정사항 / 리스크** 로 정리
7. 캐릭터들 자리로 복귀, 회의록 .md 다운로드

캐릭터를 누르면 그 팀장과 **1:1 대화**로 바뀝니다 (IDE에서 모델 바꿔가며 쓰는 느낌).

## 3. 현재 구현 (MVP, `office/index.html`)

- [x] 픽셀 오피스 + 6명 캐릭터, 걷기/타이핑/말풍선 애니메이션
- [x] 회의 모드 (1~2바퀴) / 1:1 모드
- [x] 팀장별 모델 변경 + OpenRouter 전체 모델 목록 자동완성
- [x] 스트리밍 답변, 중단 버튼
- [x] 키 없으면 데모 모드 (가짜 답변으로 화면 체험)
- [x] 회의록 브라우저 저장 + 마크다운 다운로드
- [x] 모바일 화면 대응

### 쓰는 법
1. [openrouter.ai](https://openrouter.ai) 가입 → Credits 충전($5~10이면 충분히 테스트) → Keys에서 키 발급
2. `office/index.html` 열기 (GitHub Pages 켜면 폰에서 바로 접속)
3. ⚙ 팀·모델 설정 → 키 붙여넣기 → "모델 목록 불러오기" → 팀장별 모델 선택 → 저장
4. 안건 입력 → 회의 소집

> ⚠️ 키는 그 브라우저의 localStorage에만 저장됩니다. 남의 PC에서 쓰지 마시고,
> OpenRouter 대시보드에서 키별 월 사용 한도를 꼭 걸어두세요.

## 5. Codex 작업 지시서 (복사해서 Codex에 붙여넣기)

```
레포 jalppajin1/jalme-dashboard 의 office/index.html 을 확장해줘.
단일 HTML 파일 구조와 기존 스타일(픽셀 다크 테마, 골드 포인트)은 유지.

1) 회의 템플릿: 안건 입력칸 위에 버튼 4개
   [신메뉴 출시] [월 결산 리뷰] [매물 검토] [숙박 컨셉]
   누르면 안건 textarea에 템플릿 문구를 채우고, 참석자 칩을 템플릿별 기본값으로 세팅.
2) 데이터 첨부: "자료 첨부" 버튼 → .csv/.txt/.md 파일 읽어서 회의 맥락에 포함
   (sysPrompt 의 [회사 맥락] 뒤에 [첨부 자료] 로 최대 8000자).
3) 팀장 추가/삭제: 설정 모달에서 팀장 추가(최대 8명), 삭제 가능. 새 팀장 책상 위치 자동 배치.
4) 회의 비용 표시: OpenRouter 응답의 usage 를 모아 회의 끝에 "이번 회의 약 $0.0X" 표시.
기존 기능(데모 모드, 1:1 모드, 회의록 다운로드)이 깨지지 않게 Playwright로 데모 모드 회의 1회 돌려 확인.
```
